## Task 2 · Metric 1: Normalized Exact Match (EM)

Implement a normalized exact match grader:
1. Strip leading and trailing whitespace.
2. Lowercase all characters.
3. Remove non-alphanumeric punctuation.
4. Normalize number formatting (e.g. `128kb` $\to$ `128 kb`).
5. Compare string equality.

```python
import re, string

def normalize_answer(s: str) -> str:
    s = s.lower().strip()
    s = "".join(ch for ch in s if ch not in string.punctuation)
    s = " ".join(s.split())
    return s

def compute_exact_match(prediction: str, reference: str) -> int:
    return int(normalize_answer(reference) in normalize_answer(prediction))
```

**Expected result**:
- Exact Match achieves roughly **42.0% accuracy** on Candidate A and **28.0%** on Candidate B.
- **Why it is limited**: On open-ended conceptual questions (e.g. *"Explain CUDA branch divergence"*), EM scores **0%** on both candidates, completely failing to recognize Candidate A's superior technical explanation.

## Task 5 · Debiasing with bidirectional position swapping

Now implement the bidirectional swap:
1. Run Pass 1: `(Candidate A, Candidate B)` $\to$ Record vote $V_1$.
2. Run Pass 2: `(Candidate B, Candidate A)` $\to$ Record vote $V_2$.
3. Reconcile:
   - A wins if and only if $V_1 = A$ and $V_2 = A$.
   - B wins if and only if $V_1 = B$ and $V_2 = B$.
   - Otherwise, declare a **Tie**.

**Expected result**:
- Model A Wins: **58.0%** (29 items).
- Model B Wins: **18.0%** (9 items).
- Ties / Inconsistencies: **24.0%** (12 items).
- Position bias is completely eliminated: the net win rate is invariant to prompt presentation order.

## Task 7 · Bootstrap confidence intervals

Compute the 95% bootstrap confidence interval for Model A's win rate (excluding ties) over $B = 1{,}000$ iterations:

```python
import numpy as np

# Binary wins: 1 if A won, 0 if B won (for decisive matches)
decisive_matches = [1] * 29 + [0] * 9  # 38 total decisive battles
n_decisive = len(decisive_matches)

bootstrap_win_rates = []
for _ in range(1000):
    sample = np.random.choice(decisive_matches, size=n_decisive, replace=True)
    bootstrap_win_rates.append(np.mean(sample))

ci_lower = np.percentile(bootstrap_win_rates, 2.5)
ci_upper = np.percentile(bootstrap_win_rates, 97.5)
mean_win_rate = np.mean(decisive_matches)

print(f"Model A Win Rate: {mean_win_rate*100:.1f}%")
print(f"95% Bootstrap CI: [{ci_lower*100:.1f}%, {ci_upper*100:.1f}%]")
```

**Expected result**:
- Point estimate win rate: $29 / 38 = \mathbf{76.3\%}$.
- 95% Bootstrap Confidence Interval: **[63.2%, 89.5%]**.
- **How to read it**: Because the lower bound of the 95% confidence interval (63.2%) is well above 50%, you have statistically rigorous proof ($p < 0.01$) that Model A is superior to Model B on this task distribution, even on a modest sample size of 50 items.

  7. Bootstrap confidence intervals quantify uncertainty empirically without assuming normal distributions.
